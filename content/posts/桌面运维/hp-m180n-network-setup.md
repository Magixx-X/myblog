HP Color LaserJet Pro MFP M180n 的联网配置，全程不需要装驱动工具，靠打印机自带的 Web 管理界面就能完成。

## 第一步：获取打印机当前 IP 地址

1. 在打印机控制面板上，找到并**长按**"彩色复印"按钮。
2. 持续按压三秒以上，打印机将自动打印网络状态页。
3. 从打印输出中记录打印机的当前 IP 地址。

## 第二步：访问打印机管理界面

1. 确保计算机与打印机处于同一局域网内。
2. 打开计算机上的网页浏览器。
3. 在地址栏中输入第一步获取的 IP 地址，按回车键访问。
4. 浏览器将显示打印机的网络配置管理界面。

## 第三步：配置 IPv4 网络设置

1. 在打印机管理界面中，点击"网络"选项卡。
2. 选择"IPv4 配置"选项。
3. 进入网络配置界面。

## 第四步：设置静态 IP 地址

1. 选择手动 IP 配置模式。
2. 输入规划的 IP 地址、子网掩码和默认网关。
3. 确保所配置的 IP 地址：
   - 属于当前局域网的网段范围；
   - 未被其他设备占用；
   - 处于可用状态。

## 第五步：测试连接

1. 保存并应用网络配置。
2. 在计算机上添加网络打印机。
3. 使用新配置的 IP 地址进行连接。
4. 打印测试页面验证配置是否成功。

## 注意事项

- 配置前请确认网络环境参数。
- 建议记录原始配置以便恢复。
- 如遇连接问题，请检查防火墙设置和网络连通性。

## 故障排除

如果无法正常连接，依次检查：

1. 重启打印机和网络设备。
2. 验证 IP 地址冲突情况。
3. 检查网络线缆连接状态。
4. 确认计算机与打印机的网络连通性。
