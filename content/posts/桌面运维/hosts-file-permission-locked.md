title: hosts 文件被锁定无法修改
date: 2025-04-02

summary: "hosts 文件改不动，多半是文件权限被收紧。给当前用户加上完全控制权即可。"
---

配置系统环境时经常需要改电脑的 hosts 文件。有些时候 hosts 文件被锁定了权限，用编辑器保存会提示"拒绝访问"。按下面的步骤放开权限即可。

1. 打开路径：

   ```
   C:\Windows\System32\drivers\etc
   ```

2. 右键 `hosts` 文件 → **属性** → **安全** → **编辑** → **添加** → 输入对象名称。

   在"输入对象名称"里填 `everyone`，点击确定。

3. 把 `everyone` 的权限改为**允许 完全控制**，然后 应用 → 确定。

这样 hosts 文件就可以正常修改了。

> 改完之后如果只是临时改一次，建议顺手把 `everyone` 的"完全控制"去掉，恢复到默认权限——hosts 文件是恶意软件常改的目标，权限放开太久不是好事。
