Excel 2010 默认使用 **MDI（多文档界面）** 模式——所有工作簿都在一个大的 Excel 主窗口内打开，共用一个菜单栏和边框。切来切去只能靠"窗口"菜单，很容易点错。

直到 Excel 2013 及以后的版本，微软才改成 **SDI（单文档界面）**，每个文件有独立窗口。

如果因为某些老系统或插件必须留在 Excel 2010，又想要独立窗口，下面两种办法都可行，按推荐程度排序。

## 方法一：修改注册表（最彻底，一劳永逸）

这是最有效的做法：改完之后双击文件，它就会自动在新窗口打开。

> **警告**：修改注册表有风险，请严格按照步骤操作。改之前可以先把要动的键导出备份一份。

1. 按 `Win + R`，输入 `regedit`，回车打开"注册表编辑器"。
2. 需要修改 `.xlsx`（Excel 2007-2010 格式）和 `.xls`（老格式）两种打开方式。

### 第一步：修改 .xlsx 配置

1. 在注册表左侧找到路径：

   ```
   HKEY_CLASSES_ROOT\Excel.Sheet.12\shell\Open
   ```

2. **删除 `ddeexec` 文件夹**：在 `Open` 目录下会看到一个名为 `ddeexec` 的文件夹，右键点击 → 删除（或者重命名为 `ddeexec_old` 以防万一）。
3. **修改 `command` 值**：点击 `Open` 下面的 `command` 文件夹，在右侧双击 `(默认)`（或 `(Default)`）。你会看到类似这样的数值数据：

   ```
   "C:\Program Files\Microsoft Office\Office14\EXCEL.EXE" /dde
   ```

   把它改成（注意那个空格和引号）：

   ```
   "C:\Program Files\Microsoft Office\Office14\EXCEL.EXE" "%1"
   ```

   也就是**只把结尾的 `/dde` 替换成 `"%1"`**，前面的路径不要动，保留原样。
4. 同样在 `command` 文件夹下，如果看到还有一个名为 `command` 的子键，也做同样的操作（没有则忽略）。

### 第二步：修改 .xls 配置（如果你常用老格式文件）

1. 在注册表中找到路径：

   ```
   HKEY_CLASSES_ROOT\Excel.Sheet.8\shell\Open
   ```

2. 重复上面的步骤：
   - 删除 `ddeexec` 文件夹。
   - 进入 `command` 文件夹，修改 `(默认)` 的值，将结尾的 `/dde` 改为 `"%1"`。

完成后关闭注册表，重启电脑（或注销重登）。此时双击打开两个 Excel 文件，它们就是两个完全独立的窗口了。

## 方法二：手动开启新窗口（不修改系统，最安全）

不想动注册表的话，可以用这个操作习惯：

1. 先双击打开第一个 Excel 文件。
2. **不要**直接双击第二个文件。
3. 按住键盘上的 `Shift` 键不放，然后用鼠标左键点击任务栏上的 Excel 图标（或者在开始菜单点 Excel 程序）。
4. 这会强制启动一个新的 Excel 空白程序窗口。
5. 把第二个文件拖拽到这个新的空白窗口里。

这样两个文件就是完全独立的窗口。

## 要改哪几个注册表项

几个键值对应不同的文件格式，按需要改：

### 1. Excel.Sheet.12（最重要 ★★★）

- 对应文件后缀：`.xlsx`
- 说明：Excel 2007、2010 及以后版本默认使用的"开放 XML 格式"。
- 必要性：**必须修改**。这是现在最常遇到的文件格式，不改它，绝大多数新文件还是会挤在一起。

### 2. Excel.Sheet.8（很重要 ★★☆）

- 对应文件后缀：`.xls`（97-2003 版本）
- 说明：经典的 Excel 二进制格式。虽然现在推崇 `.xlsx`，但工作中（特别是从老系统导出的报表、别人发来的老文件）依然很常见。
- 必要性：**强烈建议修改**。否则打开一个 `.xlsx` 和一个 `.xls` 时，体验会不一致。

### 3. Excel.Sheet.5（极少见 ☆☆☆）

- 对应文件后缀：`.xls`（Excel 5.0/95 版本）
- 说明：1995 年左右的古董格式。后缀名也是 `.xls`，但内部结构和 `Sheet.8` 不同。
- 必要性：**可选**。除非涉及非常古老的历史数据归档，否则几乎遇不到。为了系统行为一致，顺手改了也无妨。

### 4. 带宏的文件（.xlsm）

如果你平时会用到带宏的文件，还需要修改这个项：

- 键名：`HKEY_CLASSES_ROOT\Excel.SheetMacroEnabled.12\shell\Open`
- 对应文件后缀：`.xlsm`
- 说明：不改这个，打开带宏的表格时它依然会在旧窗口里合并打开。操作步骤和上面完全一样（删 `ddeexec`，改 `command`）。

## 总结建议

为了彻底解决问题，按下面的顺序依次修改：

1. `Excel.Sheet.12`（搞定 `.xlsx`）
2. `Excel.Sheet.8`（搞定 `.xls`）
3. `Excel.SheetMacroEnabled.12`（搞定 `.xlsm`，如果用得到）

`Excel.Sheet.5` 改不改随你，影响不大。所有项的方法完全一样：**删除 `ddeexec`，在 `command` 路径末尾把 `/dde` 改成 `%1`**。
