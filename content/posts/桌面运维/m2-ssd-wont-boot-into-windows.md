## 问题

使用 M.2 固态硬盘安装 Windows 系统（尤其是 Windows 7）时，电脑启动后卡在 Windows 徽标界面，无法进入操作系统。这种情况通常发生在新安装系统的过程中。

## 原因

导致这一问题的主要原因是**系统缺少对 M.2 硬盘的驱动程序**。此外，USB 3.0 驱动缺失也可能导致安装过程中无法正常使用鼠标、键盘。

Windows 7 原版镜像发布于 M.2 普及之前，自带驱动里没有对应的存储控制器驱动，所以装完后系统读不到系统盘。

## 解决方案

1. **进入 PE 系统**：使用 PE U 盘启动计算机，进入 PE 系统。
2. **安装驱动总裁**：在 PE 系统中选择安装驱动总裁。
3. **安装 M.2 和 USB 3.0 驱动**：启动驱动总裁，软件会自动检测系统硬件并提供相应的驱动程序。找到并选择 **M.2 硬盘驱动**和 **USB 3.0 驱动**，点击安装，等待驱动安装完成。
4. **重启电脑**：驱动安装完成后，关闭驱动总裁，重启计算机。确保在 BIOS 中设置正确的启动顺序，选择 M.2 固态硬盘作为第一启动项。
5. **检查系统是否正常启动**：电脑重启后，使用 M.2 固态硬盘可以顺利进入 Windows 系统。

> 如果是要全新安装，更省事的做法是在制作安装盘时就把 M.2 和 USB 3.0 驱动注入镜像（例如用驱动总裁或 DISM 离线注入），避免装完再进 PE 补驱动。
