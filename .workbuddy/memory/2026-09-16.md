### 环境事实（以后会反复用到）

- **git 不在 bash 工具的 PATH 里**。真实路径：
  `C:\Users\Bill\.workbuddy\binaries\PortableGit\versions\1.2.0\cmd\git.exe`（版本 2.55.0）
  用法：`export PATH="/usr/bin:/bin:/c/Windows/System32:/c/Users/Bill/.workbuddy/binaries/PortableGit/versions/1.2.0/cmd:$PATH"`
- 系统里**没有**独立安装的 Git for Windows（`Program Files\Git` 不存在），
  只有 WorkBuddy 自带的 PortableGit。
- PortableGit 自带 Git Credential Manager（`mingw64/bin/git-credential-manager.exe`），
  所以 `git config --global credential.helper manager` 可用，推送走浏览器登录，无需手搓 PAT。
- **`git diff --cached --name-only` 会把中文路径显示成八进制转义**（`"\345\220\257..."`），
  导致按中文 grep 找不到文件。要加 `-c core.quotepath=false`。
